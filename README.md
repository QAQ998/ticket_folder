# 私人电子票夹

给影迷朋友的私人电子票夹。每看完一场电影，就把手里的实体票根拍下来，连同影院、座位、时间和一点当时的心情一起收好。它不想做另一个电影清单或评分社区，只想安静地替你保存那些真正走进影院的瞬间。

## v1 功能

- 票根采集：支持拍摄实体票根，或从相册导入已有票根照片
- 票面识别：基于 Apple Vision 在设备端识别票面文字，辅助提取电影名、时间、影院、影厅、座位和票价
- 信息校对：识别结果进入可编辑表单，保存前由用户确认和修正
- 电影资料补全：通过 The Movie Database（TMDB）检索影片，并补全海报、导演、年份等基础资料
- 本地资料库：使用 SwiftData 保存观影记录，票根原图和海报缓存保存在本机
- 私人票夹体验：提供票夹式首页、票根详情、搜索、编辑和删除能力

## 技术说明

- Apple Vision 是苹果提供的计算机视觉框架，可用于图片和视频中的文本识别、物体检测、图像分析等任务。这里用它识别电影票照片里的文字。
- 设备端 OCR 指识别过程直接在 iPhone 上完成，不把票根图片上传到服务器。优点是隐私好、速度稳定、没有云端识别费用；缺点是票面反光、模糊、角度倾斜、字体太小或版式复杂时，识别结果仍需要人工校对。
- TMDB 没有写错，它是 The Movie Database 的常用缩写。这个项目用 TMDB API 查询电影资料和海报；如果没有配置 API Key，App 仍然可以手动录入电影信息。

## 不在 v1 范围

- 豆瓣主页或影评同步
- 账号系统和云同步
- 手动上传电影海报
- 服务器端 OCR
- 社交分享或公开主页

## TMDB API Key

当前 `Info.plist` 里的 `TMDB_API_KEY` 默认留空。留空时 App 仍可手动保存电影资料；填入 TMDB API key 后，电影搜索和海报缓存能力会启用。

后续建议把 key 改为通过本地 `Local.xcconfig` 或后端代理注入，避免把真实密钥提交到 GitHub。
