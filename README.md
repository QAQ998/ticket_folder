# 私人电子票夹

给影迷朋友的私人电子票夹。每看完一场电影，就把手里的实体票根拍下来，连同影院、座位、时间和一点当时的心情一起收好。它不想做另一个电影清单或评分社区，只想安静地替你保存那些真正走进影院的瞬间。

## 核心能力

- 票根采集：支持拍摄实体票根，或从相册导入已有票根照片
- 票面识别：基于 Apple Vision 在设备端识别票面文字，辅助提取电影名、时间、影院、影厅、座位和票价
- 信息校对：识别结果进入可编辑表单，保存前由用户确认和修正
- 电影资料补全：通过 The Movie Database（TMDB）检索影片，并补全海报、导演、年份等基础资料
- 本地资料库：使用 SwiftData 保存观影记录，票根原图和海报缓存保存在本机
- 私人票夹体验：提供票夹式首页、票根详情、搜索、编辑和删除能力

## 当前版本

- 平台：原生 iOS App，优先适配 iPhone
- 数据策略：观影记录、票根图片和海报缓存均保存在本机
- 资料来源：电影基础资料来自 TMDB；当无法匹配影片或未配置 API Key 时，支持手动录入文字资料
- 隐私策略：票根 OCR 在设备端完成，不依赖服务器上传图片识别
- 产品边界：当前版本聚焦私人票根管理，不包含账号体系、云同步、社交分享、公开主页或豆瓣影评同步

## 配置

`Info.plist` 中的 `TMDB_API_KEY` 默认留空。填入 TMDB API Key 后，电影搜索、资料补全和海报缓存能力会启用；未配置时，App 仍可完成本地票根录入和手动电影资料维护。

正式发布前建议改为通过本地构建配置或后端代理注入 API Key，避免将真实密钥提交到仓库。
